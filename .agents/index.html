Cách hệ thống chạy

Từ request của bạn → routing → agent + skill → kết quả. Không load hết 16 agent mỗi lần.

01
Request

Chat / slash (/create, /review…) hoặc mô tả tự nhiên.

02
Rules + Manifest

RULES.md + active-agents.json (stack đã detect).

03
Intelligent routing

Chọn agent phù hợp (FE / BE / security…). Multi-domain → orchestrator.

04
Load skills

Chỉ skill khớp when_to_use — tiết kiệm 40–70% context.

05
Execute + remember

Làm việc theo protocol; /remember lưu ADR/convention.

Socratic Gate: Feature mới / yêu cầu mơ hồ → hỏi mục đích, user, scope trước khi code. Complex → có thể cần {task-slug}.md.
